How to read it
  Event      = at least one of the state's sample points has an observed cell >= threshold.
  Forecast x = wettest forecast among those same points at that lead time.
  BSS        = Brier skill score vs. always predicting the long-run base rate.
               >= 0.10 useful | 0.02-0.10 marginal | below 0.02 no skill. (1.0 = perfect)
  POD / FAR / CSI = hit rate / false-alarm ratio / critical success index.
  'det'  = plain yes/no: forecast >= threshold.  'cal>=50%' = calibrated chance >= 50%.
  'persist' = same as yesterday (the baseline a forecast must beat).
  Events with fewer than 30 cases in the test period are marked 'too few events'.

NOT COVERED: storms/gusts. IMD publishes no gridded gust or thunderstorm observations, so
there is nothing to score them against. predict.py shows them as raw and UNVERIFIED.
