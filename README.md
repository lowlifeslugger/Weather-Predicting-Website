# Weather-Predicting-Website

Repository to show the creation of a weather prediction website built during and for a college-level hackathon, with the end goal to preserve as much of it as possible.

---

## Features

- **Interactive Global Map:** Visualise country-level and state-level weather risk indices[cite: 9, 10].
- **India State breakdown:** In-depth regional mapping with dedicated state zooming and risk breakdown[cite: 9, 10].
- **ERA5 Reanalysis Calibration:** Weather metrics calibrated against ERA5 reanalysis data for accurate local predictions[cite: 9, 11].
- **Comprehensive Daily Metrics:** Real-time visibility into max/min temperatures, humidity, wind speed, wind gusts, sunshine hours, cloud cover, and precipitation probability[cite: 10, 11].
- **Retro Cyberpunk Interface:** Built with custom neon styling, interactive tooltips, and map toggles[cite: 9, 10, 11].
